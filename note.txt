2. LOCAL RUNNING INSTRUCTIONS
-------------------------------------------------------------------
Since the project uses ES6 Modules (import/export), index.html cannot be opened directly via file:// in some browsers due to CORS policies. You MUST run it via a local development server:
- Option A: If using VS Code, right-click index.html and select "Open with Live Server".
- Option B: Open terminal in this folder and run:
  python -m http.server 8000
  Then access http://localhost:8000 in your browser.

4. NETLIFY SETUP & DEPLOYMENT INSTRUCTIONS
-------------------------------------------------------------------
To host the site on Netlify:
1. Log in to Netlify CLI in your terminal:
   npx netlify login
   (This will open a browser window for you to log in)
2. Initialize deployment link (select Create & configure new site):
   npx netlify init
3. Build and deploy to production:
   npx netlify deploy --prod
   (This will upload the site and output a live URL)
4. To change the Netlify subdomain:
   - Go to your Netlify dashboard.
   - Click your site -> Site settings -> General -> Site details.
   - Click "Change site name" and update to: msa-sport-informer
   - Save.
